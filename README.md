# 🏏 Virat Kohli — International Century Analysis Dashboard

An interactive **Power BI Data Analytics project** exploring Virat Kohli's 71 international centuries across formats, opponents, venues, match conditions and career years.

![Virat Kohli Dashboard](dashboard.png)

---

## 📊 Project Overview

This project analyzes Virat Kohli's international centuries to identify performance patterns and meaningful insights using data visualization.

The dashboard transforms raw cricket data into an interactive visual report that allows users to explore Virat Kohli's century-scoring performance from different perspectives.

---

## 🎯 Project Objective

The main objective of this project is to:

- Analyze century-scoring trends over the years
- Compare performance across different formats
- Identify opponents against whom centuries were scored
- Compare Home vs Away performances
- Analyze performance as Captain vs Non-Captain
- Study batting position and venues
- Analyze Out vs Not Out performances
- Explore Man of the Match performances
- Identify highest-scoring innings
- Present insights through an interactive Power BI dashboard
