# Virat Kohli International Century Analysis Dashboard

## 📊 Project Overview
An interactive Power BI dashboard analyzing Virat Kohli's 71 international centuries.

## 🛠️ Tools Used
- Power BI
- Excel / CSV
- Data Cleaning
- Data Visualization

## 📈 Analysis Covered
- Centuries by Format
- Centuries by Year
- Centuries by Opponent
- Match Results
- Home vs Away Performance
- Captain vs Non-Captain
- Batting Position
- Top Venues
- Out vs Not Out
- Man of the Match
- Average Score Analysis

## 🔑 Key Insights
- Total Centuries: 71
- Highest Score: 254
- Most Centuries vs Australia: 15
- Away Centuries: 39
- Home Centuries: 32
- Centuries as Captain: 41
- Centuries as Non-Captain: 30

## 📌 Dashboard
Built using Microsoft Power BI with interactive KPIs, charts and a Year slicer.
